# 電腦版設計規劃（Desktop）

> 版本：v0.2（2026/09）｜狀態：§9 已確認；**D1 已實作**（教練頁、找教練），其餘依 §7 分期
> 相關：PRD §3.4 M10「桌機是加分，不是縮放」、§4.2 導覽；BRAND_DESIGN_BRIEF §8.3、§10.4

## 1. 為什麼要做、給誰用

| 誰 | 什麼情境用電腦 | 最在意什麼 |
|---|---|---|
| **搜尋來的訪客** | 在 Google 搜「大安 匹克球 教練」、點教練放在 IG 個人簡介的連結 | 第一眼就看懂這位教練、價格、時段，能直接約 |
| **比較中的學生** | 上班時間開好幾個分頁比較教練、課程 | 資訊密度高、能並排比較、不用一直點進點出 |
| **教練** | 晚上在家排課、對帳、改教練頁 | 表格化管理、一次看一週、批次操作 |
| **團主** | 上班時開團、看報名名單 | 名單與候補一目了然 |

LINE 內（LIFF）永遠是手機版；電腦版只在一般瀏覽器、寬度 ≥ 1024px 時出現。

## 2. 現況

- 學生端每個畫面都是「手機 App」結構：固定高度的外框 `.app-shell`（最寬 480px）＋內部捲動 `.scroll`＋底部固定按鈕 `.sticky-cta`＋底部分頁 `TabBar`。
- 電腦上看到的是**手機畫面放在畫面中間**，兩側灰底。
- 唯一的電腦版是教練後台「我的教練頁」編輯器（≥ 1024px 左表單、右手機框預覽，`.console-wide`）。
- 頁面是「框內捲動」不是「整頁捲動」：瀏覽器的捲軸、回上一頁記住位置、Ctrl+F 捲動、滑鼠滾輪在框外無效，電腦上都不自然，電腦版要改回整頁捲動。

## 3. 尺寸分級與版面格線

| 名稱 | 寬度 | 版面 | 導覽 |
|---|---|---|---|
| 手機 | < 640px | 現在的設計，不動 | 底部分頁 |
| 平板 | 640–1023px | 加寬的手機版：單欄、內容加寬到 720px、卡片一排 2 張（已做電腦版的頁面才加寬） | 底部分頁 |
| 電腦 | 1024–1439px | 12 欄格線、欄距 24px、內容最寬 1200px、左右留白 32px | 頂部導覽列 |
| 寬螢幕 | ≥ 1440px | 同電腦，內容不再加寬（最寬 1200px 置中），避免一行字太長 | 頂部導覽列 |

- 內文維持 16px；電腦版標題放大一級（H1 32→40px）。
- 一行文字最長約 40 個中文字（自介、問與答），太寬就改兩欄。
- 測試寬度：1024、1280、1366、1440、1920。

## 4. 共用規則：手機元件 → 電腦元件

| 手機 | 電腦 | 說明 |
|---|---|---|
| 底部分頁 `TabBar` | **頂部導覽列** `TopNav` | 左：Logo；中：首頁／找教練／球局／球場／第一次打；右：我的課、通知、頭像選單（我的、切換教練模式、登出）。現成 `.nav` 樣式可沿用 |
| `AppBar`（返回＋置中標題） | **麵包屑**＋頁面標題 | 例：首頁 › 找教練 › Mia 林 |
| 底部固定按鈕 `.sticky-cta` | **右側固定預約卡** | 捲動時黏在右欄頂端（Airbnb 房源頁的做法） |
| 底部滑出 `Sheet` | **置中對話框** 或 **下拉選單** | 篩選改成左側欄或下拉；確認類改對話框 |
| 橫向滑動列表 | **格線** | 推薦教練一排 3–4 張、相簿改拼貼 |
| 篩選 chips 列 | **左側篩選欄**（常用的留在上方 chips） | 篩選即時套用，不用按「套用」 |
| 點擊 | 點擊＋**滑鼠移入效果**＋**鍵盤操作** | 卡片 hover 浮起；所有操作可用 Tab／Enter 完成；焦點框清楚 |
| 框內捲動 | **整頁捲動** | 見 §2 |

- 左 8 欄內容、右 4 欄預約卡。預約卡直接選方案、日期、時段，選完才進預約頁（帶入選好的時段），少一步。

- 「可約時段」在電腦上改成一週的格子表，一眼看完整週。
- 分享給 Google 的 SEO 結構（標題、description、結構化資料 `Person`／`Service`）跟這頁一起做。

## 6. 技術做法

- **同一套程式碼**，不另做一個網站。大部分靠 CSS 依寬度切換，只有少數元件需要電腦版專用版本。
- **外框**：新增 `DesktopShell`。≥ 1024px 時 `.app-shell` 取消 480px 限制與固定高度、改回整頁捲動；`TopNav` 在電腦上顯示、`TabBar` 隱藏。
- **頁面版型**：共用幾個版型 class，各頁套用：
  - `.dk-page`：置中 1200px 容器
  - `.dk-main-aside`：左 8 欄內容＋右 4 欄黏性側欄（教練頁、預約、球場詳情）
  - `.dk-filter-list`：左篩選欄＋右結果（找教練、球局、球場）
  - `.dk-console`：左側選單＋右內容（教練後台）
- **行為不同的元件**（Sheet → 對話框、比較列 → 比較表）用 `useMediaQuery` 切換；其餘純 CSS，避免伺服器端與瀏覽器端畫面不一致（hydration mismatch）。
- **圖片**：`next/image` 的 `sizes` 依電腦版寬度更新，封面圖改用較大的尺寸。
- **不做**：伺服器端判斷裝置（User-Agent）、另開 `m.` 網域。

## 8. 驗收

- 1024／1280／1440／1920 寬度下沒有橫向捲軸、沒有被截斷的文字。
- 只用鍵盤能完成「找教練 → 選時段 → 送出預約」。
- 瀏覽器縮放 200% 版面不破。
- 手機版畫面與行為完全不變（視覺回歸截圖比對）。
- 教練頁 Lighthouse SEO ≥ 95。

## 9. 已確認（2026/09）

1. **優先順序**：先做教練頁＋找教練（D1）。
2. **平板**：640–1023px 當「加寬的手機版」。
3. **設計稿**：不另外畫，直接做成網頁，在 Vercel 預覽網址上看、上面改（D0 併進 D1）。
4. **訪客**：只看外層基本資訊，教練頁細節與預約要登入才解鎖，引導註冊（見 §5.1）。
5. **頂部導覽**：暫定 首頁／找教練／球局／球場／第一次打，之後看數據調整。

## 10. D1 實作狀態

- `TopNav`（`components/pk/TopNav.tsx`）：電腦版頂部導覽，登入後顯示「我的課」與頭像選單（我的、切換教練模式、登出），訪客顯示「登入／註冊」。
- 版面開關：頁面在捲動容器加上 `.dk` 才會在 ≥1024px 變成電腦版（`styles/desktop.css`）；沒加的頁面仍是置中的手機畫面。教練後台編輯器的手機預覽不受影響。
- 電腦版上 Bottom Sheet 自動變成置中對話框，Toast、比較列固定在視窗底部。
- Demo 的登入狀態：「我的」或電腦版頭像選單的「登出（Demo：看訪客畫面）」可切到訪客，登入框的「用 LINE 登入」切回來。
