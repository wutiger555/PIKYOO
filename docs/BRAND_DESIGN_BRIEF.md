## 1. 品牌核心

| | |
|---|---|
| 名稱 | **PIKYOO**（英）／**匹友**（中） |
| 命名 | PIK = Pickleball；YOO = You／友。匹友 = 匹克球 × 朋友 × 你 |
| 一句話 | 雙北匹克球的「開團、找課、找場」入口 |
| 品牌承諾 | **「想打球，來匹友就對了。」** 讓每個人都找得到一個場、一堂課、一群人 |
| 主標語 | 找場、找課、找球友。｜Find your court. Find your coach. Find your game. |
| 副標語 | Find your people. ／ 一起打球吧。 |

### 1.1 品牌個性
| 是 | 不是 |
|---|---|
| 友善、像球友 | 幼稚、卡通化 |
| 有活力 | 吵鬧、螢光刺眼 |
| 簡單、直覺 | 陽春、模板感 |
| 現代、成熟、可信賴 | 冰冷的「運動管理系統」、企業 SaaS 感 |
| 社群感、溫度 | 交友軟體感 |

**成熟度的定義：** 一致的設計系統（色彩、字級、間距、元件狀態都有規則）、清楚的資訊層級、克制的用色、完整的空狀態／錯誤狀態／載入狀態。成熟 ≠ 保守；是「每個細節都有被想過」。

### 1.2 目標使用者（設計時請記得他們）
- **新手小安**（29，上班族）：第一次接觸，怕跟不上 → 需要安心感、清楚資訊
- **團主阿凱**（38，管 3 個 LINE 群組）：每週開 4 局 → 需要快、少打字
- **Mia 教練**（32，協會認證）：招生靠 Threads / IG → 需要專業、好看、可分享的頁面
- 中高齡玩家比例高 → 字要夠大、對比要夠、操作要單純

## 3. 差異化原則（必須遵守）

1. **不用 Tailwind 預設色**，也不用橘／藍／綠／青／紫當主色。
2. **不用純白底 + 純黑字**：用暖米白紙感底色與「墨色」文字，一眼就和競品不同。
3. **一個招牌色，克制使用**：招牌色只用在「行動、重點、品牌時刻」，不大面積鋪滿。
4. **Logo 不用球拍交叉、寫實球、火焰、盾牌徽章、吉祥物。**
5. **有自己的招牌元件**（見 §7），讓截圖一看就知道是匹友。
6. **中文是主角**：版面以繁體中文排版為優先設計，不是英文版翻譯。

## 4. Logo 簡報

### 4.1 概念方向（請先各發展一版，再收斂成一個）

**方向 A（推薦）｜「匹」＝ 一個場、兩個人**
「匹」字的結構：外框「匚」像一座球場的邊線與網，裡面的「儿」像兩個人。
→ 把「匹」幾何化成符號：外框是球場線，裡面兩筆是兩位球友。意義直接對應「匹友 = 一起在場上的朋友」，而且是中文字，競品不可能撞。

**方向 B｜YOO 的雙 O ＝ 你和我**
字標中的「OO」是兩顆球／兩個人並肩，其中一個 O 帶有匹克球特有的圓孔紋理（僅用在大尺寸）。
→ 以字標為主的品牌，適合與方向 A 的符號搭配。

**方向 C｜球場線構成的 P**
用匹克球場的「廚房線（非截擊區）」比例構成字母 P。
→ 幾何、現代，但文化記憶點較弱，作為對照組。

### 4.2 Logo 規格
| 項目 | 要求 |
|---|---|
| 組合 | ① 符號 ② 字標（PIKYOO） ③ 中英組合（符號 + PIKYOO + 匹友）橫式與直式 |
| 最小尺寸 | 符號在 16×16 favicon 仍可辨識 |
| 圓形裁切 | LINE 官方帳號大頭貼是圓形 → 符號在圓形內要成立 |
| 單色 | 墨色單色版、反白版都要成立 |
| 應用 | App icon / PWA icon（192、512、maskable）、favicon、LINE 官方帳號大頭貼、圖文選單、OG 預覽圖、分享圖浮水印 |
| 字標字體 | 客製或修改現有字體，字母圓角與符號線條一致；避免過細 |

## 5. 色彩系統（起點提案）

### 5.1 品牌色
| Token | 名稱 | 色碼 | 用途 |
|---|---|---|---|
| `ink` | 墨 | `#14231C` | 主要文字、深色面、Logo |
| `paper` | 米 | `#FAF6EC` | 主要背景（暖紙感，取代純白） |
| `pik` | 匹黃 | `#FFD84D` | 招牌色：主按鈕底色、重點標示、品牌時刻（像螢光筆、也像球） |
| `surface` | 白 | `#FFFFFF` | 卡片表面（浮在米色背景上） |
| `line` | 線 | `#E6E0D2` | 分隔線、邊框（呼應球場線） |
| `muted` | 灰墨 | `#5E6B64` | 次要文字 |

**規則：**
- 匹黃 **只當底色，不當文字色**（黃字在米色底上對比僅 1.28:1）。主按鈕 = 匹黃底 + 墨色字。
- 已驗證對比（WCAG）：墨字/米底 15.1:1、墨字/匹黃底 11.8:1、灰墨字/米底 5.2:1、灰墨字/白底 5.6:1，皆通過 AA。
- 深色模式：墨色底 + 米色字 + 匹黃重點（也適合 LINE Flex 卡片與分享圖，辨識度高）。

### 5.2 功能色（狀態用，不作品牌色）
| 狀態 | 用途 |
|---|---|
| 成功 | 報名成功、已確認 |
| 警示 | 快額滿、候補中、AI 低信心欄位 |
| 錯誤 | 失敗、取消 |
| 資訊 | 提示 |
> 請設計一組與品牌色和諧、飽和度較低的功能色；**每個狀態都要有文字或圖示，不只靠顏色**。

### 5.3 程度色階
程度：新手、2.0、2.5、3.0、3.5、4.0、4.5+
→ 請設計一組**連續色階**（例如從淺到深的單一色相，或墨色到匹黃的漸層），色盲友善，徽章上一律同時顯示數字。

## 6. 字體與排版（起點提案）

| 用途 | 字體 | 說明 |
|---|---|---|
| 中文 UI 與內文 | **Noto Sans TC（思源黑體）** | 成熟、清晰、免費 |
| 英文與數字 | **Inter** 或同級 Grotesk | 時間、價格、程度一律用**等寬數字（tabular）** |
| 行銷大標（選用） | 可探索更有個性的中文標題字（如圓體類 jf open 粉圓），**只用於行銷與空狀態**，UI 內不用 | 增加親和力，但避免整體變幼稚 |

**字級（Mobile，起點）：** 大標 28 / 標題 22 / 小標 18 / 內文 16 / 輔助 14 / 最小 12（僅標籤）
**行高：** 中文內文 1.6；標題 1.3
**時間是主角：** 球局卡片上的時間用大字（22–28）＋ 等寬數字

## 7. 招牌元件（讓 PIKYOO 一眼被認出來）

| 元件 | 描述 |
|---|---|
| **球局票卡 Game Ticket** | 球局卡片設計成「入場票」：左側大字時間與日期，中間一條虛線打孔分隔，右側場地、程度、費用；底部是座位列。在列表、LINE Flex 卡片、分享圖中保持一致 |
| **座位列 Seat Row** | 用一排圓形座位表示名額：已報名 = 頭像、空位 = 虛線圓、候補 = 數字。「●●●○ 缺 1」一眼看懂 |
| **程度徽章 Level Chip** | 固定形狀 + 色階 + 數字（例：`3.0–3.5`），全站一致 |
| **認證徽章 Credential Badge** | 顯示發證單位與等級（協會認證／總會丙級／PPR／DUPR 3.85）；已驗證與自填有明顯區別 |
| **新手友善標記** | 🌱 或客製小芽圖示 + 「新手友善」文字 |
| **球場線裝飾 Court Line Motif** | 以匹克球場線條（邊線、廚房線、中線）作為分隔線、背景紋理與插圖語言，取代通用幾何裝飾 |
| **螢光筆強調 Highlighter** | 匹黃像螢光筆一樣畫在重點文字下方（例：「缺 2」「今晚」），也用在 AI 一貼成局中標示「需要確認」的欄位 |
| **底部行動列 Sticky CTA** | 固定在底部：左側價格／狀態，右側主按鈕（匹黃）；所有詳情頁一致 |

## 8. 介面與互動原則

### 8.1 手機優先（詳見 PRD §3.4）
- 主要按鈕在拇指可及的底部；篩選用 Bottom Sheet；快速篩選用橫向 Chips
- 從 LINE 卡片點進來到報名完成 ≤ 3 次點擊
- 點擊區 ≥ 44px、內文 ≥ 16px、支援系統字級放大
- 報名、收藏採樂觀更新；載入用 Skeleton，不用轉圈圈

### 8.2 LINE LIFF 內的限制
- LINE 內建瀏覽器頂部已有 LINE 的 header → **頁面不要再放高大的頂部導覽**，用精簡標題列
- 注意底部安全區域（iPhone Home Indicator）
- LINE 內不能用 Google 登入，登入頁以「LINE 登入」為主

### 8.3 桌機
- 教練後台、管理後台用多欄 + 表格化管理
- SEO 訪客看到的教練頁、課程頁、球場頁要像「一張完整的名片」，資訊層級清楚

### 8.4 圖像與插圖
- 照片：真實的台灣球場與球友（多年齡層、自然光、不擺拍），不要歐美素材圖
- 插圖：以球場線條 + 簡單幾何人形構成，單色或雙色（墨 + 匹黃），用在空狀態、新手專區、Onboarding
- 圖示：線性圖示、圓角端點、線寬與 Logo 一致

### 8.5 動態
- 短、輕、有目的：報名成功時座位「填入」的動畫；候補遞補成功的提示
- 避免彈跳、閃爍等刺激性動效

## 11. 文案語氣

| 原則 | 例 |
|---|---|
| 像球友講話，不像系統 | ✅「週六缺 2，來嗎？」 ❌「本活動尚有 2 個名額」 |
| 短、口語、有溫度 | ✅「報名成功！週六見 👋」 ❌「您的報名已完成」 |
| 新手不被嚇到 | ✅「第一次打？這幾堂課很適合你」 |
| 空狀態給下一步 | ✅「這週還沒有局，自己開一團吧？」 |
| 錯誤不怪使用者 | ✅「網路好像斷了，再試一次？」 |
