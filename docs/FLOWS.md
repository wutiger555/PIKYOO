# PIKYOO 使用者流程與 MVP 精簡（2026-11-05）

> 目的：快速上線、快速累積使用者。原則是**直觀、流暢、少步驟**；太複雜的功能先收起來。
> 依據：2026-11-05 在手機寬度實際操作示範網站（`pikyoo-demo.vercel.app`）、讀 `main`（#75）的程式碼與資料庫函式、查正式資料庫。
> **2026-11-05 owner 決定**：教練頁的「匹克球檔案」保留（重要功能，教練頁與編輯頁都留）；評價現在就做。其餘「先收起來」照 §4。
> **已完成（#78）**：評價、新加入、教練取消一堂課、這幾天不開放、送審前要有收款資訊、教練「今天」的接下來的課、再約同一堂。
> 標記：✅ 正式站可用（開放登入後就是真的）　🟡 只有示範　⬜ 沒有　✂️ 建議 MVP 先收起來　➕ 建議 MVP 補上

---

## 0. 一句話

**MVP 只做一條主線：學生找到教練 → 約課 → 教練答應 → 付款 → 上課 → 收到筆記。** 教練在手機上（從 LINE 打開網站）管理這條線。球局、球場是引流的配角，揪朋友、比較、AI 開團等先收起來。

教練後台：**MVP 用網站版**（手機從 LINE 打開即可，已接真資料）。App 的教練後台畫面做好了但還不能登入，等有 Apple 開發者帳號再上。

## 1. 學生

### 1.1 第一次來
| 步驟 | 現在 | 建議 |
|---|---|---|
| 從 IG／LINE 連結進到教練頁或首頁 | ✅ 訪客看得到照片、資格、價格、介紹，其餘要登入 | 保留 |
| 按「用 LINE 登入」 | ✅（正式站尚未開啟） | 保留：一鍵、免填表 |
| 首次設定：暱稱 → 程度 → 常打區域（3 步，可略過） | ✅ | **改成可以先跳過**、預約時才問程度；第一次進來就填 3 步會流失人 |

### 1.2 找教練
| 步驟 | 現在 | 建議 |
|---|---|---|
| 「我是【程度】，想在【地點】上」 | ✅ | 保留，這是最直覺的入口 |
| 下面三排按鈕：類型、已認證／新手友善、教學專長 | ✅ | ✂️ 收成**一排**（體驗課／一對一／小班＋「更多篩選」），第一屏要看得到教練 |
| 排序、列表／地圖 | ✅ | 保留（地圖是亮點） |
| 教練卡「比較」、找教練右上「收藏」 | ✅ | ✂️ 先收起來：教練少的時候用不到 |

### 1.3 看教練頁
現在 9 段：評價 → 資格 → 課程 → 時段 → 關於我（含上課步驟、適合誰、匹克球檔案、上課照片）→ 問與答 → 地點，外加揪團說明、取消規則、付款方式。

建議 MVP 版：**評價（或「新教練」）→ 課程與價格 → 最近可約時段 → 關於我（一段文字＋照片）→ 問與答 → 地點**。
- ✂️ 「揪朋友一起上」說明、「上課怎麼進行 3 步」、「適合誰」清單先不顯示（教練不用填，頁面也短不少）
- **匹克球檔案保留**（owner 2026-11-05）
- 取消規則、付款方式縮成預約頁上的一行
- ➕ **新教練沒有評價時**顯示「新加入的教練」而不是空白星星（目前評價都是示範資料，真教練一定是 0 則）

### 1.4 預約
現在 4 步：選課程 → 選時段 → 自己上還是揪朋友 → 選付款方式 → 送出。

建議 2 步：**選課程 → 選時段 → 送出**（可附一句話給教練）。
- ✂️ 「揪朋友一起上」先拿掉（正式站本來就隱藏）
- ✂️ 付款方式改到**教練答應後**再選（那時才需要付錢，也少一個決定）；只開教練有填的方式
- 取消規則留一行小字

### 1.5 預約之後（三個狀態：等教練回覆 → 去付款 → 完成）
| 情況 | 現在 | 說明 |
|---|---|---|
| 教練答應 | ✅ LINE＋站內通知 → 付款頁 | |
| 教練婉拒 | ✅ 通知「換一個時段」 | |
| 48 小時沒回 | ✅ 自動取消、通知，不佔名額 | |
| 學生取消 | ✅ 一鍵取消，教練收到通知 | 遲到取消的費用只顯示規則、沒有自動收（錢不經過平台，MVP 可接受） |
| 學生想改期 | 取消再約一次 | MVP 可接受 |
| 教練要取消／下雨改期 | ⬜ **正式站做不到** | ➕ 見 2.4 |

### 1.6 付款（錢直接給教練，平台不經手）
| 方式 | 流程 | 現在 |
|---|---|---|
| 銀行轉帳 | 掃轉帳 QR（或複製帳號）→ 按「我付好了」（末五碼選填）→ 教練確認收到 | ✅ |
| LINE Pay | 開教練的收款連結 → 按「我付好了」→ 教練確認 | ✅ |
| 現場付現 | 上課時給，教練可出示 QR 讓學生當場轉 | ✅ |
| 附轉帳截圖 | | ⬜ 做好在 PR #58，等資料庫變更 |
| 前一晚 20:00 提醒，沒付的附付款頁 | | ✅ |

### 1.7 上課後
| | 現在 | 建議 |
|---|---|---|
| 收到教練的課後筆記（通知＋我的課） | ✅ | 保留，這是留住學生的重點 |
| 評價教練 | 🟡 示範有按鈕，正式站**沒有評價功能** | ➕ MVP 做最簡單版：上完課隔天通知「給 Mia 一個評價」→ 1–5 星＋一句話 |
| 再約一堂 | 🟡 | ➕ 筆記和評價下面放「再約同一堂」，一鍵帶到選時段 |

### 1.8 配角：球局、球場
| | 現在 | 建議 |
|---|---|---|
| 找球局、報名／候補／取消、分享到 LINE | ✅ | 保留（引流） |
| 開團 | ✅（含「AI 一貼成局」規則解析） | 保留「自己填」，✂️ AI 一貼先收起來 |

## 2. 教練

### 2.1 開始使用（第一次）
| 步驟 | 現在 | 建議 |
|---|---|---|
| 用 LINE 登入 → 「我是教練」→ 填網址與名字 | ✅ | 保留 |
| 編輯教練頁 → 送審 → PIKYOO 核准後公開 | ✅ | 保留審核（品質把關） |
| 教練頁編輯：照片、基本資料、關於我、教學專長、適合誰、匹克球檔案、擅長教、經歷與證照、授課地點、付款、分享素材 | ✅ 欄位非常多 | ✂️ 分成**必填 6 項**一頁填完：照片、一句話介紹、區域與授課地點、程度範圍、教學專長、課程與價格。其餘（關於我、經歷證照）選填、收合；「擅長教」與「教學專長」重複，留一個 |
| 填每週可約時段 | ✅（在另一個分頁） | 併進同一個設定頁 |
| 填收款帳戶（銀行從清單選） | ✅（藏在收款頁右上角） | ➕ 放進開始使用的步驟裡，不填就不能送審（不然學生答應後付不了錢） |

### 2.2 每天（教練後台「今天」）
✅ 已有：待確認預約（答應／婉拒，顯示學生程度與留言）、學生提問（公開回覆）、今天的課、上過還沒寫筆記的課。

建議：**所有待辦都在「今天」**，教練一打開就知道要做什麼：
1. 預約等你答應
2. 學生說付好了 → 確認收到（現在在「收款」分頁，➕ 併進來）
3. 提問等你回
4. 上完的課寫筆記
5. 今天、明天的課

### 2.3 收款
✅ 學生說付好了 → 確認收到（可一次多筆）；還沒付 → LINE 提醒（12 小時一次）或現場出示 QR；前一晚自動提醒可關。
建議保留「收款」為列表與對帳用，待辦的部分在「今天」處理。

### 2.4 臨時狀況（➕ MVP 一定要補）
| 情況 | 現在 | 建議做法（越簡單越好） |
|---|---|---|
| 這堂課要取消（生病、下雨） | ⬜ 正式站只有學生能取消 | 課程卡上「取消這堂」→ 選原因 → 學生收到 LINE 通知、全額不收 |
| 某天不能上課（出國、比賽） | ⬜ 每週時段會一直開 | 在時段設定加「這天不開放」選日期，學生預約頁就看不到 |

### 2.5 後台分頁
| | 現在 | 建議 |
|---|---|---|
| 網站 | 今天／課程時段／教練頁／收款（4 個） | **今天／收款／我的頁面（3 個）**：課程、時段、收款帳戶都併進「我的頁面」，和 App 一致 |
| App | 今天／學生／我的頁面，另有行事曆、點名、套票、提醒 | 🟡 只有示範；等 App 登入（需要 Apple 開發者帳號）再接真資料 |

## 4. MVP 清單

### ✂️ 先收起來（程式保留，畫面不顯示）
揪朋友一起上、教練比較、收藏、AI 一貼成局、教練頁的適合誰／上課 3 步／上課照片區、教練編輯頁的「擅長教」重複清單、分享招生素材、套票（10 堂）方案的特殊處理、App。

### ➕ 要補（都是小功能）
1. 教練取消一堂課（通知學生）
2. 教練關掉某一天
3. 上完課的評價（星等＋一句話），新教練顯示「新加入」
4. 「再約同一堂」
5. 收款帳戶放進教練開始使用的步驟
6. 「學生說付好了」併進教練「今天」
7. 預約簡化成 2 步；付款方式改到答應後選
8. 找教練篩選收成一排；首次設定可跳過

### 開門（見 BACKEND §13）
營運者名稱與 Email（隱私權政策）、確認取消規則數字、第一批 3–5 位真教練、清掉示範資料、開啟正式站 LINE 登入、升級 Supabase Pro。
